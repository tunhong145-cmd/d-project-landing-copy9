# 複製倉庫九

D 項目獨立落地頁副本，自訂域名待綁定。

## 版本入口

| 版本 | 路徑 |
|---|---|
| C | `/` |
| F | `/f/` |
| G | `/g/` |
| I | `/i/` |
| J | `/j/` |
| K | `/k/` |
| M | `/m/` |

`/e/` 僅保留舊入口，導向 `/m/`，不是額外的第八個版本。

- 固定像素設定編號：`copy9`。每個版本獨立配置，未配置不發送 FB 事件，不回退到其他倉庫。
- M 版沿用內部 E 設定鍵，保持既有訂單歸類及 LINE 分組。
- G、M 採用已確認的新版視覺；其他版本沿用主落地頁倉庫的現有版本。
- LINE、資料提交與分流使用 D 項目既有服務，不包含後台、資料庫備份或歷史客戶資料。
- 倉庫不預設 CNAME。請在 Settings → Pages 綁定新域名，再更新 D 後台的倉庫域名標籤。

建立來源：主倉庫 `410e655`、G 版 `4c7e32d`、M 版 `5b1cb11`。
